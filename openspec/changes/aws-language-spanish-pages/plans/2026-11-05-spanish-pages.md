## Rules common to every group
- English msgids, written naturally (they are the source language); the Spanish translation is EXACTLY the text the page/message shows on `main` today (copy it byte for byte; keep «», ¿?, accents, spacing). Before changing a string, record its current Spanish text (`git show main:<path>`), and pin it with a Spanish test (see below).
- Whole-sentence msgids with `%d`/`%s`/`%(name)s` placeholders; never assemble sentences from translated fragments. Plurals with `ngettext` (Python) and `{% trans count=n %}...{% pluralize %}...{% endtrans %}` (templates); Spanish plural form (1 vs rest) from the `.po` header (`nplurals=2; plural=(n != 1);`). Old-style trans: a literal `%` in a trans block is `%%`; variables must be simple names (declare them in the `trans` tag).
- Domain modules without a request get optional keyword arguments `gettext` / `ngettext` defaulting to identity (`lambda s: s`, `lambda one, many, n: one if n == 1 else many`); handlers pass `self._` / `self.n_`. Constants become `N_("...")` (from `cms.locale`) translated at use. Do not translate log messages, `assert` texts, data keys (`usuarios_nuevos`, `participaciones_nuevas`, `equipos_quitados`, `movidas_al_grupo_principal`, ...), URL query keys (`repetido`), or the CSV header aliases in the import script.
- Extraction: refresh the catalog after each group: `.venv/bin/python setup.py extract_messages -F babel_mapping_aws.cfg -o cms/locale/aws.pot`, then `.venv/bin/python setup.py update_catalog -D aws -i cms/locale/aws.pot -l es`; fill every new Spanish entry (no fuzzy, no empty; fix wrong fuzzy matches Babel makes); `msgfmt --statistics -c` must show 0 fuzzy / 0 untranslated; `.mo` files are gitignored; the tests must not need `.mo` or setuptools (build the Spanish Translation from `aws.po` with `read_po`/`write_mo` as `translated_pages_test.py` does: move that helper into a small non-test module `cmstestsuite/unit_tests/server/admin/aws_catalog.py` in group 1 and reuse it).
- Macros: a macro with text imported without context does not see the per-request `gettext`; add `with context` to its imports if you wrap text inside one (list them in the commit).
- Tests: existing tests that assert Spanish text now assert the English msgid (identity translation) keeping their intent; for each group add Spanish PIN tests (render/call with the Spanish catalog and assert the exact Spanish strings as on `main`: at least one per distinct message shape: plain, with count (1, 2, 0), with placeholders, and the notifications) so that "the Spanish stays word for word" is proven; add the English/Spanish page tests for the Scenarios of the delta spec named in `tasks.md`. Name or comment every test with its Scenario. One pytest process at a time, asyncio group only (these files do not import gevent).
- Commits: Conventional Commits, English, last line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; tick the task box(es) of the group in `tasks.md` inside the commit. A group may use several commits (code, tests, catalog) but each commit must leave the aws catalog test green.
- Stop and report instead of improvising when a message cannot be made a whole-sentence msgid without changing today's Spanish, or when a test asserts Spanish text in a way that you cannot map to the new rule.
